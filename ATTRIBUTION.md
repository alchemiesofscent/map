# Attribution and licensing notes

This repository scaffold is a starter package, not a final publication dataset.

## Source text

The passage identifiers and draft translations in `data/raw_sections.sample.json` come from the supplied project extraction. Add the exact First1KGreek repository URL, commit hash, or TEI source path before publication.

## Pleiades

The local authority file uses Pleiades identifiers and URIs for ancient places. Pleiades states that its data is shared under Creative Commons Attribution 3.0. Verify identifiers and representative coordinates against the current Pleiades API or data dump before reuse in a scholarly release.

Pleiades: https://pleiades.stoa.org/
Pleiades API: https://api.pleiades.stoa.org/
Pleiades downloads: https://pleiades.stoa.org/downloads

## Digital Atlas of the Roman Empire

Some starter coordinates are noted as DARE-derived where the search result exposed a WGS84 position associated with a Pleiades ID. Check DARE's current license and attribution terms before publication.

Digital Atlas of the Roman Empire: https://imperium.ahlfeldt.se/
