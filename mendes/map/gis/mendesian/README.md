# The Mendesian (the Dark Mendesian)

Ingredient provenance from the House of Mendes evidence records (`mendes/data/claims.json`).

Human-readable companion to `points.geojson`/`points.csv` (ancient claims), `modern-points.geojson`/`.csv` (modern identifications) and `routes.geojson` in this folder. Coordinates are decimal degrees, WGS 84, given `lat, lon`. See `../README.md` for field definitions and the caveats on route geometry.
