# Review Datasets

## `periplus_sites_webmap_scrape.json`

Generated by:

```sh
python3 scripts/scrape_periplus_sites.py --out data/review/periplus_sites_webmap_scrape.json
```

The scraper reads the reviewed ordered site list embedded in the script, fetches
the QGIS2Web export at
`https://raw.githubusercontent.com/pbarchi/periplus-interactive-webmap/main/data/PeriplusSites_3.js`,
and follows each available `github_link` to the Navigating the Periplus
location page.

The output is a review/import sidecar only. It does not update
`data/generated/periplus/places_authority.json`, route files, or the local
review ledger.

Generated dataset timestamp: see the top-level `generated_at` field.

Key fields:

- `source_order`, `input_name`, `source_name`, `source_feature_index`
- `is_split_from_input`, used for `Zafar Diodoros Island`, which expands to
  `Zafar` and `Diodōros Island`
- route and Periplus fields from the webmap export
- `pleiades_id` and `pleiades_uri` parsed from the webmap `pleiades_link`
- `lat` and `lon` from point geometry, null when the source geometry is null
- `github_location_url`, page-derived modern identification, country, ancient
  source, bibliography entries, and compact `page_metadata`
- `source_urls`, retaining the webmap, location page, and Pleiades source URLs

Copyright-safe passage policy: the scraper does not bulk-copy Casson's
translation passages. It stores `passage_present: true` when a page has a
passage and keeps only `passage_excerpt`, capped at 240 characters, for review
orientation.

## `section_place_sequence.json`

Human-reviewed chapter-level focus sequences for the scrollytelling viewer.
These records decide which places inside a source section become scroll/chip
focus stops and which named places remain context-only.

`scripts/build_route_views.py` copies the reviewed records into
`data/generated/periplus/route_views.json` under each view's `section_focus`
array. Add future chapter curation here rather than hand-editing generated
runtime JSON.

Each section record contains:

- `section_order`
- `card_title`
- `review_status`: `draft`, `reviewed`, or `needs_followup`
- `visit_sequence`: ordered focus places with `display_name`, optional
  `route_site_key`, optional `source_name`, optional `note`, and
  `geometry_policy`
- `context_places`: named places that should stay linkable as context but must
  not become focus stops

## Retired Materia Review Sidecars

The Materia reset no longer promotes accepted links from
`simples_provenance_review.csv`, `simples_entry_provenance_claims.json`, or
generated LLM adjudication JSON. Accepted Materia claims now live in annotated
TEI `placeName` elements under `data/tei/annotated/` and are normalized into
`data/generated/simples/provenance_entry_claims.json`.

Use `docs/materia_tei_ingredient_journeys.md` when adding more ingredient
journeys. Do not hand-edit generated JSON.

## `materia_draft_translations.json`

Fresh draft English translations for the current Materia TEI passages. These
are viewer-orientation text only. Do not use them as extraction evidence,
provenance authority, or a replacement for the annotated Greek TEI claims.
